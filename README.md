# GamersHub 🎮

A responsive gaming e‑commerce storefront that showcases games, accessories and peripherals. Built to practice modern UI design and clean, maintainable CSS layouts.

---

## 🚀 What is GamersHub?
GamersHub is a simple, responsive online store mockup for gamers. It displays product listings for:
- 🎧 Headsets and audio gear
- 🕹️ Controllers and input devices
- ⌨️ Keyboards and mice
- 🎮 Games (digital/boxed) and bundles
- 🛒 Shopping flow and product cards

This project focuses on layout, visual polish and a pleasant shopping experience using only HTML and CSS.

---

## 🎯 Why this project?
- To practice modern UI design patterns and responsive layouts.
- To learn clean, semantic HTML structure and scalable CSS.
- To prototype an elegant product-focused ecommerce UI without backend complexity.
- To provide a reusable front-end template for portfolios or future projects.

---

## ✨ Features
- Fully responsive layout (mobile → desktop)
- Clean product cards with images, prices and CTAs
- Simple header/nav and footer for easy navigation
- Accessible and semantic HTML structure
- Pure CSS styling — no JavaScript required for the mockup

## 📦 Getting started
1. Clone the repo:
   git clone https://github.com/WysemanTalal/GamersHub.git

   - Double-click the file or run a simple static server (e.g., `npx http-server`).
3. Explore the pages and responsive breakpoints.
